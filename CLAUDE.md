# Lukyanov Hydraulic Integrator — Godot simulation

Simulation of a 1D Lukyanov hydraulic integrator (Soviet water-based analog computer, 1936).
Purpose: a digital twin of a home-built rig (5 vessels + movable tank + constant-level outlet),
used to compare simulated water levels against real measurements from timelapse footage.

## Stack
- Godot 4.7, GDScript only, statically typed (`:=`, typed params/returns).
- Viewport 1920×1080, stretch `canvas_items` + aspect `keep` (Steam Deck 1280×800 scales down with bars), `gl_compatibility` renderer.
- Indentation: tabs (Godot default).
- In-game UI text and code comments are in Russian; keep it that way.

## Structure
- `project.godot` — main scene `res://syringe_rig.tscn`.
- `main.tscn` — original abstract view: `Node2D` "Main" with `lukyanov_integrator.gd`.
- `lukyanov_integrator.gd` (`class_name LukyanovIntegrator`) — model, input, CSV logging, and `_draw()` rendering.
- `syringe_rig.tscn` / `syringe_rig.gd` — extends `LukyanovIntegrator`; DIY build scheme from 60 ml syringes
  (vessels), 3-way stopcocks, IV drip lines with roller clamps (resistances), bottle tank on a stand.
  Derives `vessel_height_cm` from syringe volume/diameter, shows levels in cm and ml, parts list,
  Poiseuille estimate of open-line t½. Overrides `_draw()` and wraps `_unhandled_input()` for F1.
  Layout for 1920×1080: part sizes ×`U` (1.35), fonts `FS_SMALL`/`FS`/`FS_BIG` (20/24/30). Long how-to text lives in the F1 manual, not on screen.
- `docs/instruction.pdf` — Russian build/calibration/calculation manual (A4 landscape).
  Generated by `docs/build_instruction.py` (reportlab + pypdfium2, Arial from C:/Windows/Fonts), which also
  renders `docs/pages/page_N.png` at 1054 px height (viewport minus hint line); F1 in `syringe_rig` shows those PNGs (Godot can't render PDF).
  After editing the text or rig defaults, rerun the script — its constants mirror `syringe_rig.gd` defaults.
  `FONT_K` scales all font sizes (2.0).

## Model
- Each vessel = one layer of the heated body; water level = temperature.
- Update: `dh_i/dt = (h_{i-1} − 2·h_i + h_{i+1}) / τ` (discrete heat equation).
- Boundaries: left = `tank_level_cm` (movable tank), right = `outlet_level_cm` (constant-level drain).
- `τ = 2 · pair_half_time_s / ln 2`; `pair_half_time_s` comes from calibrating the real rig
  (time for the level difference between two neighbouring vessels to halve).
- Explicit Euler, sub-stepped so `dt/τ ≤ 0.2` (stable limit is 0.5). Levels clamped to `[0, vessel_height_cm]`.
- Steady state with a constant tank must be a straight line — use as a sanity check after changes.

## Data
- `S` key writes `user://lukyanov_levels.csv`: `t_s,tank_cm,h1_cm..hN_cm`, one row per `record_interval_s`.
- This CSV format is what real measurements are compared against — don't change columns without reason.

## Controls
↑/↓ tank ±1 cm · Space pause · +/− sim speed ×2 · R reset · S save CSV.
F1 manual overlay (←/→, PgUp/PgDn, wheel or click to flip, Home first page, O open PDF externally, Esc/F1 close).
Mouse (`syringe_rig`): drag the tank bottle, the drain tube end, or inside a syringe (sets its level);
wheel = ±0.1 cm on those; top buttons for pause/speed/reset/CSV/manual. Positions come from
`make_input_local(event)`, so tests can feed synthetic `InputEventMouse*` straight into `_unhandled_input`.

## Conventions
- Keep the physics (`_step`, `_tau`) independent from rendering so it can be moved to a separate
  class or tested headless later.
- Exported vars are the user-facing tuning knobs; keep defaults matching the physical rig.
- Run: open in Godot 4.7 and press F5. Headless check: `godot --headless --path . --quit`.
